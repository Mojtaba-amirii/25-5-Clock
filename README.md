# 25 + 5 Clock

A Pomodoro-style 25 + 5 clock built with React, Redux Toolkit, and React
Bootstrap.

## Available Scripts

### `npm start`

Starts the Vite development server. Open the URL shown in the terminal.

### `npm test`

Runs the Vitest test suite once.

### `npm run test:watch`

Runs Vitest in watch mode while developing.

### `npm run build`

Builds the app for production into the `dist` directory.

## Tooling

This project uses Vite for development and production builds. Create React App
was deprecated by the React team in 2025, so the app no longer depends on its
unmaintained `react-scripts` dependency tree.
